Transcriptome Analysis

Run the current DESeq2 B73-vs-Y12 transcriptome workflow, inspect PCA/volcano results, and reproduce the archived maize KEGG GSEA method.

Scope

Toolkits → Transcriptome Analysis is the RNA-seq/count-oriented utility in ProtVis. It is separate from Downstream analysis → DEP analysis, which is designed for proteomics abundance data.

The current module performs three connected analyses from the uploaded transcriptome files:

  • PCA with PCAtools;
  • differential expression with DESeq2;
  • KEGG GSEA using the bundled maize/teosinte KEGG background derived from the archived Enrichmentdb2 annotation.

Use this module for raw count-style gene-expression data appropriate for DESeq2. Do not feed normalized continuous proteomics intensities into this interface.

Current interface

The screenshot below predates the new GSEA card but still shows the PCA/volcano portion of the same module. ProtVis 0.9.1 now adds a third full-width KEGG Gene Set Enrichment Analysis card below these two panels.

Required files

Both inputs are Excel .xlsx files.

Gene Expression Data

The first column must be named exactly:

GeneID

All remaining columns are sample count columns.

Group Information

The workbook must contain:

Sample
Group

Sample values must match the expression-matrix sample columns. Additional metadata columns can be used for PCA color/shape mappings.

Current biological contrast

ImportantThe current DESeq2 comparison is fixed to B73 versus Y12

The present dev implementation runs DESeq2::results(dds, contrast = c("Group", "B73", "Y12")). Therefore the Group column must contain B73 and Y12 for the differential-expression and downstream GSEA workflow described here.

If another biological contrast is required, do not assume the current GUI is a generic arbitrary-group RNA-seq model without changing the implementation.

Run the transcriptome analysis

  1. Upload Gene Expression Data and Group Information.
  2. Confirm that sample columns are non-negative raw counts and sample names match.
  3. Configure PCA color/shape/presentation settings.
  4. Configure volcano presentation settings.
  5. Configure GSEA settings if the archived KEGG workflow is required.
  6. Click Run Analysis.

For DESeq2, ProtVis converts GeneID to row names, applies ceiling() to sample values, reorders columns to the Group Information sample order, constructs DESeqDataSetFromMatrix(..., design = ~ Group), runs DESeq(), and extracts B73 versus Y12.

Differential-expression rule

The current classification is:

Up:   padj < 0.05 and log2FoldChange >  1
Down: padj < 0.05 and log2FoldChange < -1

Everything else is Not significant. The volcano y-axis is -log10(adjusted p-value) and the dashed guide lines correspond to adjusted p-value 0.05 and log2 fold change ±1.

PCA

PCA is calculated from the uploaded expression matrix with PCAtools::pca() and can be colored/shaped by fields from Group Information. The interface supports custom group colors, sample labels, group encircling, confidence ellipses, point size, ellipse transparency and export dimensions.

Use the PCA Data table/export together with the plot; do not infer exact sample coordinates from the image alone.

KEGG GSEA

The current module reproduces the archived maize transcriptome GSEA logic from 02.MaizeTeosintePro/01.src/RNAseq.R.

Bundled background

ProtVis uses the built-in maize KEGG background generated from the verified Enrichmentdb2 annotation. The runtime background contains TERM, GENE and NAME relationships. Expression and group tables are not bundled; users supply them at runtime.

Ranking metrics

The GSEA settings allow:

  • log2 fold change — default and historical RNAseq.R method;
  • DESeq2 Wald statistic;
  • Signed -log10(P-value).

Historical defaults are:

Setting Default
Minimum gene-set size 5
Maximum gene-set size 500
GSEA p-value cutoff 1
Pathways shown in dotplot 10

Complete ranked universe

ProtVis now matches the archived RNA-seq workflow by passing the complete finite DESeq2 ranked list to clusterProfiler::GSEA(). Genes without KEGG annotation remain in the ranked universe; KEGG annotation defines pathway membership through TERM2GENE.

Only a minimal overlap check is applied before GSEA. This is important for exact reproduction because pre-filtering the ranked list to KEGG-annotated genes changes the enrichment universe and can change NES/p-values.

GSEA result panels

The current card contains:

  • Dotplot;
  • Enrichment Curve;
  • GSEA Results;
  • Ranked List;
  • Archived Reference.

After analysis, the status badges report the number of ranked genes/pathways, selected ranking metric, selected pathway NES and the built-in maize KEGG background. If pathway 00940 is present, Phenylpropanoid biosynthesis is selected preferentially for the enrichment curve.

Archived GSEA reference

The Archived Reference tab shows the historical 00940 phenylpropanoid result extracted from the archived KEGGenrich.xlsx. It is a regression/reference record only and is not used as the active GSEA result.

This separation is deliberate: the active result must be recalculated from the uploaded expression/group data, while the frozen reference exists to verify historical reproduction.

Exports

Current downloads include:

  • PCA PDF and PCA coordinates;
  • volcano PDF and DEG result CSV;
  • GSEA dotplot PDF;
  • GSEA enrichment-curve PDF;
  • full GSEA result CSV;
  • complete ranked-list CSV.

Schema-v4 recording

When an active ProtVis_dataset is available, Run Analysis records one immutable deg_deseq2 run with method DESeq2 + KEGG GSEA. The run stores the differential-expression table, top DEGs, PCA scores, GSEA result/ranked list when successful, statistics, plot data/configuration and the fixed B73/Y12 contrast.

Warning

Do not convert continuous normalized measurements into pseudo-counts simply to make them pass this interface. The DESeq2 model and archived GSEA reproduction assume RNA-seq count-style input and the current fixed B73/Y12 design.
